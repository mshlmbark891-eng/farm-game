# مزرعة الأعمال

لعبة مزرعة بمنظور أيزومتري مبنية بـ Phaser داخل ملف HTML واحد (`index.html`).

## التشغيل
افتح `index.html` في المتصفح، أو شغّلها من GitHub Pages.

## المزايا
- ري تلقائي فور الزراعة
- هاتف داخل اللعبة: شراء البذور، توظيف العمال، شراء الأدوات، خدمات أخرى
- لمس وعصا تحكم للهاتف، ولوحة مفاتيح للكمبيوتر (WASD / E / P)
